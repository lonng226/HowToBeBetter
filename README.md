# 高性价比处事指南

悟处世谋双略，吃透人心博弈，遇事从容破局。

讲怎么在开口之前先看清局面，怎么从一个人的言行里读出可用的信息，怎么把话说出去而不把人得罪，怎么在办事时给自己留余地。也讲人情往来的账怎么算，被人算计时怎么接招，情绪上头时怎么先把自己稳住，还有哪些事一不小心就把自己搭进去。

64 条建议，每条写明花掉什么、换回什么、证据有多硬，来源只引期刊论文和官方法条文件。

不用全做：这是一份备选单，不是任务清单——挑走一两条就算数，作者自己也没做到其中大部分。

书里的内容可能过时，也可能有错。真去办事、谈判、打官司时，以对方的态度、当地部门和专业人士的说法为准。发现写错了，欢迎[提 issue](https://github.com/lonng226/HowToBeBetter/issues)。

## 怎么读

- **不用全做**：这是一份备选单，不是任务清单。挑走一两条就算数，剩下的放着，需要时再回来查。想挑省力的，看下面「只想看最省力的」那条。
- **看不懂那串数字**：每条都有一行「说人话」。它把「收益」栏里那些研究里的写法，翻成「被人骗过的关系会先降级」「借出去的钱要不回来」这样的日常说法。它只用「收益」栏已经写到的内容，不添新数字。只看这一行就够拿主意。
- **条目之间会互相指路**（「见第 1 节第 2 条」这种）：每处指路后面都写着指向什么（「见第 1 节第 2 条（重要决定前把消息从一个人那里扩到三条）」）。不翻过去也知道说的是哪条。
- **想按顺序读**：每节内的先后顺序不代表性价比高低。条目多的节开头有一段分组导览，按主题挑着看就行。
- **只看结论最硬的**：证据等级 A 的一共 18 条，出处是荟萃分析、大型队列或随机对照试验，能说出降了或高了多少。
- **只想看最省力的**：性价比「极高」的 4 条，不花钱、用时少、不需要毅力，收益又落在最大一档。「高」的 33 条次之。
- **看到「别把自己搭进去」这类节标题不用紧张**：节标题说的是这一节想防住的事，不是说底下每条都在让你别干什么。真正要做的动作写在条目标题里，一律动词开头，自己就写清了是「做什么」还是「别做什么」。

每条建议长这样：

```markdown
### 1. 谈事先问清楚「这事最后谁拍板」
<!-- 成本标签: 钱=0 时间=少 毅力=些 收益=中 口径=关系 -->
- 成本：不花钱。开口多问一句。难在对方可能觉得你在绕弯子。
- 说人话：谈判谈到最后才发现，跟你聊的人做不了主，是最亏的浪费。开场就把三件事问出来：这事最后谁定，什么时候定，你这一层要不要点头。问出来你自己好办，对方也省得陪你白聊。
- 收益：行业调查里，复杂型生意中约七成没接触到真正的决策者就谈输了。这不是对照试验，是 446 家企业销售负责人自述的数字。
- 证据等级：B
- 来源：Dixon A, Adamson B (2011). The Challenger Sale. HarperBusiness.
- 备注：数字来自销售方的行业调查，不是随机对照试验，方向可信，比例不必当真。
```

## 四种资源

这本书想帮你多留住的不只是道理，一共四样东西：

- **关系**：让别人愿意继续跟你打交道，而不是一次性把信任花完
- **金钱**：少踩坑、少吃亏，少花冤枉钱，把钱花在确定的地方
- **时间与精力**：活着的时间不花在没有回报的事上，每天的注意力和体力少被白白耗掉
- **心力**：情绪上头时不至于做决定，不至于在夜里翻来覆去

每一条建议都回答两个问题：要花掉什么（钱/时间/毅力），能换回什么（关系/金钱/时间精力/心力）。每条的性价比档由这四项成本加上收益量级算出来。

**不同口径之间不做比较。**「谈崩了还能留住这个关系」和「一年省下两千块」不在一把尺子上，没法分高下。同一节里口径不同的条目，数字也不放在一起换算。

**一条建议的好处落在谁身上，是分档的。** 按「这份好处将来有多大可能回到你自己身上」从高到低：① **你自己**；② **配偶和直系亲属**（父母、子女、孙子女）；③ **朋友、同事和其他亲属**——互惠关系，帮出去的将来可能回来；④ **陌生人**——最低一档，但不是零：回报的概率小，而且你不了解对方性格，还有被讹、被反咬的一面。写到第 ④ 档时好处和风险一起写。

## 证据分级

每条建议都标注证据等级：

| 等级 | 含义 |
| --- | --- |
| A | 有具体数字可查，出处是多项研究合并起来的荟萃分析、跟踪很多人很多年的大型队列，或者随机分组的试验（RCT），能说出差了多少（HR、RR、下降百分比） |
| B | 有研究支持，但说不出一个确切数字；或者只有小样本、单独一项研究撑着；法律和政策类条目指引到了法条或官方文件原文 |
| C | 作者自己的经验，或者大家公认的做法，没有直接的研究文献 |

全书 64 条中 A 级 18 条、B 级 44 条、C 级 2 条，另有 15 条标注了争议。所有来源只引原始文献（期刊论文附 DOI，或全国人大、法院、国务院、公安部等官方文件原文），不引二手转述。不确定的数字标「待核实」。

A 级只说明「有具体数字、出处可核」，不说明这个数字一定是因果。A 级里既有随机分组的试验，也有只跟踪记录、不分组的研究，后者分不清是这件事起了作用，还是做这件事的人本来就更稳妥。哪一种看收益栏：写着「随机分成两组」的是前者，写着「只记录、不分组」的是后者。

收益栏和说人话里的百分比，多数是比不做的人好多少或差多少，不是每一百人里多几个。同样低 12%，本来风险就高的人少掉的数，远多于本来风险就很低的人。所以先看说人话里写的是哪些人，再看那个百分比。

## 性价比档

证据等级只回答「这个数字可不可信」，不回答「这件事值不值得做」。所以每条还另外标了两样：收益量级（好处有多大）和口径（换回的是哪一类东西）。这两样加上三项成本，合出一个性价比档：

| 维度 | 取值 | 怎么定的 |
| --- | --- | --- |
| 口径 | 关系 / 金钱 / 时间精力 / 心力 | 看这条主要换回的是什么。**不同口径之间不做比较**，没法分高下 |
| 收益量级 | 大 / 中 / 小 | 照着条目自己的「收益」栏，按事先定好的界线套，不凭感觉：关系看后果（毁掉关键关系为大，关系降级为中），金钱看金额（万元级为大，数百到数千为中，几十元为小），时间看节省量（每天小时级为大，每周小时级为中，一次性为小），心力看恢复程度（大是情绪能稳住不乱，中是少费些力气，小是略微省心） |
| 性价比 | 极高 / 高 / 一般 | 好处大、三项成本都在最低档 = 极高；好处大、成本不高，或者好处中等、三项成本都在最低档 = 高；剩下的 = 一般 |

三项成本的最低档是「不花钱、用时少、不需要毅力」。「用时少」指一次花几分钟以内，或者顺手就能做。

全书 64 条中性价比极高 4 条（6%）、高 33 条（52%）、一般 27 条（42%）。中间那档条数多是有意的：收益量级本来只分大、中、小三级，再往细里切就是装出来的精确。

**这一档是作者自己的判断，不是证据**，按本书的标准它本身只算 C 级；它和证据等级是两回事，谁也不影响谁。一条可以证据是 A 级、性价比却只算一般，也可以证据只有 C 级、性价比却极高。

## 读懂数字（术语表）

正文尽量用日常说法，但引用研究的时候免不了出现几个统计名词。看不懂就查这张表。

<details>
<summary>展开 22 条术语（HR、RR、OR、队列、荟萃分析、FOI、登门槛……）</summary>

| 术语 | 意思 |
| --- | --- |
| HR | 风险比。同样一段时间里，做了某件事的那组人出事的快慢，除以没做的那组。HR 0.87 就是比没做的那组低 13%，HR 1.21 就是高 21% |
| RR | 相对风险。两组人出事的可能性之比，数字怎么读和 HR 一样 |
| OR | 比值比。也是两组的对比，只是算法和 RR 略有不同：要比的那件事很少见时，它和 RR 差不多；那件事很常见时，它会把差距说得比实际大 |
| 95% CI | 95% 置信区间。研究算出的数字总有误差，这是真实情况很可能落在的范围。倍数类的数字，范围跨过了 1；加减类的数字，范围跨过了 0，就说明两组的差别可能只是碰巧 |
| RCT | 随机对照试验。用抽签一样的办法把人分成两组，一组做这件事，一组不做，过后比结果差多少。要证明「是这件事起了作用」，这种做法最有说服力 |
| 荟萃分析 | 把很多项研究的结果凑到一起重新算，得出一个总的数字。也叫 meta 分析 |
| 队列 | 队列研究。挑一大群人跟踪很多年，记录谁出了事。能看出两件事常一起出现，但不足以证明是前一件造成了后一件 |
| 观察性 | 观察性研究。研究者只在旁边记录，不安排谁做、谁不做。结果容易被别的因素带偏（见本表的混杂、反向因果两条），数字要打点折看 |
| 混杂 | 有第三个因素同时牵动着前因和后果，让两件事看起来像有因果。比如愿意社交的人往往也更健康，分不清是哪一样在起作用 |
| 反向因果 | 因果的方向弄反了：看着像前一件引起后一件，其实是后一件引起前一件。不是压力大让人脾气差，是关系已经烂了让人压力大 |
| 相关 | 两件事一起变的方向和紧密程度，不等于谁造成谁。书里凡是相关研究，备注栏都会点出来 |
| d、g | 效应量，表示两组的差距有多大。把差距换算成「相当于几倍的常见波动幅度」：0.2 算小，0.5 中等，0.8 大 |
| FOI | 害怕显露（fear of invalidity）。一个人为了不被看出不称职，宁可少做、少说。这条研究里的测量方式是「宁可表现得平庸，也不愿冒犯错的风险」 |
| 登门槛 | 对方先给一个小好处，让你先欠上一点人情或者已经开了口，再提出真正的大要求。这是常见的一种手法 |
| 沉没成本 | 已经花掉、收不回来的成本。它不该影响你接下来的决定，但人常常被它拽住 |
| 有限注意力 | 一个人同一时间能盯住的事情是有限的，所以每加一件要操心的事，都从别处挪走一点心力 |
| 承诺升级 | 公开说过的话会让人为了不显得前后矛盾而继续走，哪怕路已经不对 |
| 社会临场感 | 旁边有没有人看着，会改变一个人的行为。人越多，越容易守规矩，也越容易跟着多数走 |
| 道德许可 | 先做了一件小坏事，心里给自己开了个口子，接着做更大的事 |
| 谈判锚点 | 谈判一开始就给出的第一个数字或条件。它会把后面的讨论拉向自己这一边，所以先开价的人和后开价的人往往谈成不一样的结果 |
| 稀缺 | 东西少、时间紧、机会只有一次的时候，人会明显更容易让步，也更容易忽略不划算的部分 |
| 沉没的沉没 | 已经不可逆的事，继续投入只会让损失更大 |
| 心理账户 | 人心里的钱不是一整笔。不同的来路、不同的用途会被分开算，所以「这是白来的」和「这是我自己挣的」会被花得不一样 |

</details>

6. [被算计了怎么接](book/06-被算计了怎么接.md)：对方先开价时事前把市场价查到手，听到「就今天」「最后期限」先问一句再决定，认出登门槛把后面要做什么问清，别人先给小好处先问是不是为了后面的要求，对方催你的时候你越要慢，谈崩的时候给对方留个台阶，认准了不划算的局趁早撤，谈判里别一次把条件全亮出来留一手。口径：金钱和心力。
7. [先把自己稳住](book/07-先把自己稳住.md)：情绪最冲的那几个小时别做决定也别回消息，心跳快胃口发紧时先用几分钟慢呼吸，被人说「你一直很能干」时把它换回一件具体的事，把「我就是这样的人」改成「我以前是这样」，每周把做不成的事列出来正式放弃其中几件，长期没进展时先改一件小事别等状态变好，睡前那段时间别去处理别人的烂摊子，心里不痛快时找一个不会传出去的人说出来。口径：心力和关系。
8. [别把自己搭进去](book/08-别把自己搭进去.md)：借出身份证银行卡手机卡之前先问对方拿去做什么，给人签字担保挂名之前先算出你出不出得起这笔钱，涉及钱权责任的事说完当场写下来，被人用「你看着办」架住时先不接话把问题拉回事实，有人当众让你难堪私下提醒一次不改就升级，每季度清一次消耗你的关系，遇到自己判断不了的涉法问题先打 12348 问一遍，觉得自己被骗了先截图存证再报警。口径：人身自由和金钱。
